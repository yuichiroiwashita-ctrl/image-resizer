# image-resizer

画像を好みのサイズにリサイズ・トリミングできるブラウザ完結型ツールです。GitHub Pages で公開しています。

## 概要

インストール不要・サーバー送信なしで画像のリサイズとトリミングができるシンプルなウェブアプリ。

## 機能

- 画像のリサイズ（幅・高さを自由に指定）
- 画像のトリミング
- ブラウザ完結処理（画像がサーバーに送信されない）
- 処理後の画像をダウンロード

## 使い方

1. 画像ファイルをアップロード
2. リサイズ・トリミングのサイズを指定
3. ダウンロードボタンで保存
